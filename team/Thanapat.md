# Broken Window ที่เคยเจอ

1. **Window คืออะไร:** การเขียนฟังก์ชันจัดการข้อมูล เชื่อมต่อฐานข้อมูล/API และการแสดงผล UI ทั้งหมดรวมอยู่ในไฟล์เดียวโดยไม่แยก Layer หรือแบ่งเป็น Component ย่อย ๆ
2. **ผลกระทบ:** ไฟล์ยาวเป็นพันบรรทัด ทำให้อ่านยาก เกิด Git Merge Conflict บ่อยครั้งเมื่อทำงานพร้อมกัน และไม่มีใครกล้าแตะโค้ดส่วนนั้นเพราะกลัวกระทบฟังก์ชันอื่น
3. **ถ้าแก้ทันทีจะป้องกันอะไร:** ช่วยให้โครงสร้างโปรเจกต์เป็นระเบียบ แบ่งหน้าที่รับผิดชอบชัดเจน (Separation of Concerns) ทำให้ทีมสามารถเข้ามาเขียน Unit Test, เพิ่มฟีเจอร์ หรือแก้ไขบั๊กได้ง่ายโดยไม่กระทบส่วนอื่น
