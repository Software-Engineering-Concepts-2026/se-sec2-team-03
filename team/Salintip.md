# Pragmatic Promise
    หนูจะพยายามเขียนโค้ดให้เป็นระเบียบ อ่านง่าย และตั้งชื่อตัวแปรหรือฟังก์ชันให้สื่อความหมาย เพื่อให้เพื่อนในทีมสามารถอ่านและแก้ไขงานต่อได้ง่าย นอกจากนี้หนูจะพยายามรับผิดชอบงานของตัวเองและส่งงานให้ตรงเวลามากขึ้น

# ทำไมอยากเรียน SE
    หนูอยากเรียน Software Engineering เพราะการพัฒนาซอฟต์แวร์ไม่ได้มีแค่การเขียนโค้ด แต่ต้องรู้จักวางแผน แบ่งงาน ทำงานร่วมกับผู้อื่น และดูแลซอฟต์แวร์ให้สามารถใช้งานได้ในระยะยาว หนูจึงอยากเรียนรู้กระบวนการทำงานที่เป็นระบบ เพื่อนำไปใช้กับการทำโปรเจกต์และการทำงานจริงในอนาคต

# Broken Window ที่เคยเจอ
- **Window คืออะไร:** 
    การละเลยไม่เขียนเอกสารกำกับ API และปล่อยชื่อตัวแปรที่สื่อความหมายไม่ชัดเจนไว้ชั่วคราว
- **ผลกระทบ:** 
    เพื่อนร่วมทีมเข้าใจการทำงานคลาดเคลื่อน จนเกิดบั๊กซ้ำซ้อนและเสียเวลาไล่โค้ดแก้งานนานกว่าเดิม
- **ถ้าแก้ทันทีจะป้องกันอะไร:** 
    ป้องกันความสับสนในการสื่อสาร ลดหนี้ทางเทคนิค (Technical Debt) และลดเวลาในการ Debug ของทั้งทีมลงได้ทันที
