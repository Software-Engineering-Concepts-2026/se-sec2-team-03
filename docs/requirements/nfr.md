# Non-Functional Requirements (NFR)

## 1. Performance

ระบบต้องตอบสนองต่อการร้องขอทั่วไปภายในเวลาไม่เกิน 2 วินาทีที่ P95 เมื่อมีข้อมูลของผู้ใช้ไม่เกิน 100 รายการ

**Measurement:**
- Response time ≤ 2 seconds ที่ P95
- Dataset ≤ 100 records


## 2. Security

ระบบต้องป้องกันการเข้าถึงข้อมูลของผู้ใช้งานโดยไม่ได้รับอนุญาต และต้องกำหนดรหัสผ่านให้มีความปลอดภัย

**Measurement:**
- รหัสผ่านต้องมีความยาวอย่างน้อย 8 ตัวอักษร
- Session timeout หลังไม่มีการใช้งาน 30 นาที
- หน้าที่เป็นข้อมูลส่วนตัวต้องสามารถเข้าถึงได้เฉพาะผู้ใช้ที่เข้าสู่ระบบแล้ว


## 3. Availability

ระบบต้องพร้อมให้ผู้ใช้งานเข้าถึงได้ในช่วงเวลาที่กำหนดของแต่ละวัน

**Measurement:**
- Uptime ≥ 99%
- ช่วงเวลาที่ต้องพร้อมใช้งาน: 08:00–22:00
- ไม่รวมช่วงเวลาที่ประกาศปิดปรับปรุงล่วงหน้า


## 4. Scalability

ระบบต้องรองรับการใช้งานพร้อมกันจากผู้ใช้หลายคนโดยไม่ทำให้ประสิทธิภาพลดลงเกินเกณฑ์ที่กำหนด

**Measurement:**
- รองรับผู้ใช้พร้อมกันอย่างน้อย 100 คน
- Response time ยังคง ≤ 2 วินาทีที่ P95
- รองรับข้อมูลอย่างน้อย 100 records ต่อผู้ใช้


## 5. Usability

ระบบต้องสามารถให้ผู้ใช้งานใหม่เรียนรู้และทำภารกิจหลักได้โดยไม่ต้องมีผู้สอน

**Measurement:**
- ผู้ใช้ใหม่สามารถสมัครสมาชิกและเข้าสู่ระบบได้ภายใน ≤ 3 นาที
- ผู้ใช้ใหม่สามารถบันทึกรายรับหรือรายจ่ายรายการแรกได้ภายใน ≤ 3 นาที
- ผู้ใช้ใหม่สามารถเพิ่มรายการสิ่งที่ต้องทำได้ภายใน ≤ 2 นาที


## 6. Data Integrity

ระบบต้องรักษาความถูกต้องของข้อมูลรายรับ รายจ่าย รายการสิ่งที่ต้องทำ และข้อมูลส่วนตัวของผู้ใช้

**Measurement:**
- ข้อมูลที่บันทึกสำเร็จต้องสามารถเรียกดูได้ 100%
- จำนวนเงินต้องเป็นค่ามากกว่าหรือเท่ากับ 0
- ระบบต้องไม่สร้างรายการซ้ำจากการส่งคำขอเดิมซ้ำ


## 7. Compatibility

ระบบต้องสามารถใช้งานผ่านเว็บเบราว์เซอร์หลักที่ผู้ใช้งานทั่วไปใช้

**Measurement:**
- รองรับ Google Chrome รุ่นปัจจุบัน
- รองรับ Microsoft Edge รุ่นปัจจุบัน
- รองรับ Mozilla Firefox รุ่นปัจจุบัน
- หน้าเว็บต้องสามารถแสดงผลบนหน้าจอความกว้างตั้งแต่ 360px ขึ้นไป


## 8. Backup and Recovery

ระบบต้องสามารถกู้คืนข้อมูลสำคัญได้เมื่อเกิดความผิดพลาดของระบบหรือข้อมูลเสียหาย

**Measurement:**
- สำรองข้อมูลอย่างน้อยวันละ 1 ครั้ง
- สามารถกู้คืนข้อมูลสำรองล่าสุดได้ภายใน ≤ 4 ชั่วโมง
- เก็บข้อมูลสำรองย้อนหลังอย่างน้อย 7 วัน
