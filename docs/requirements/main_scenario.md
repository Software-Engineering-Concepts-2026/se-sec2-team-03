# Main Scenario: การใช้งานระบบจัดการข้อมูลชีวิตประจำวัน

**Persona ที่เกี่ยวข้อง:** ผู้ใช้งาน และผู้ดูแลระบบ

**Objective:** ผู้ใช้งานต้องการใช้ระบบเพื่อจัดการข้อมูลส่วนตัว ข้อมูลการเงิน รายการสิ่งที่ต้องทำ และข้อมูลสุขภาพในชีวิตประจำวัน ขณะที่ผู้ดูแลระบบต้องการตรวจสอบและจัดการข้อมูลผู้ใช้งานภายในระบบ

**Action Sequence:** ผู้ใช้งานเริ่มจากการสมัครสมาชิกและเข้าสู่ระบบ จากนั้นสามารถบันทึกข้อมูลรายรับ รายจ่าย น้ำหนัก และเพิ่มรายการสิ่งที่ต้องทำในแต่ละวัน เมื่อมีการทำงานเสร็จ ผู้ใช้งานสามารถเปลี่ยนสถานะรายการเป็นงานที่เสร็จแล้ว และสามารถดูข้อมูลทั้งหมดที่สรุปไว้บน Dashboard เพื่อเห็นภาพรวมของตนเองได้ ในส่วนของผู้ดูแลระบบ ผู้ดูแลสามารถเข้าสู่ระบบเพื่อดูรายชื่อผู้ใช้งาน ค้นหาข้อมูลบัญชี และจัดการบัญชีที่ไม่ใช้งานโดยการลบบัญชีตามความเหมาะสม

**ปัญหาที่เจอ:** ผู้ใช้งานอาจมีข้อมูลหลายด้านที่ต้องจัดการแยกกัน เช่น รายรับ รายจ่าย งานประจำวัน และข้อมูลสุขภาพ ทำให้การติดตามข้อมูลทำได้ยากหากไม่มีระบบรวมข้อมูลไว้ในที่เดียว ส่วนผู้ดูแลระบบอาจพบปัญหาในการตรวจสอบและจัดการบัญชีผู้ใช้งานจำนวนมาก

**ผลลัพธ์ที่หวัง:** ผู้ใช้งานสามารถจัดการข้อมูลสำคัญในชีวิตประจำวันได้อย่างสะดวกและเห็นภาพรวมของข้อมูลผ่าน Dashboard ส่วนผู้ดูแลระบบสามารถตรวจสอบและจัดการบัญชีผู้ใช้งานได้อย่างเป็นระบบและมีประสิทธิภาพ
