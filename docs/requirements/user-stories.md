# User Stories

## Main Scenario

อ้างอิงจาก Main Scenario: การใช้งานระบบจัดการข้อมูลชีวิตประจำวัน

ผู้ใช้งานสามารถสมัครสมาชิก เข้าสู่ระบบ จัดการข้อมูลส่วนตัว บันทึกรายรับ รายจ่าย น้ำหนัก และรายการสิ่งที่ต้องทำ รวมถึงดูข้อมูลทั้งหมดผ่าน Dashboard ส่วนผู้ดูแลระบบสามารถตรวจสอบรายชื่อและจัดการบัญชีผู้ใช้งาน

---

### Story US-01: สมัครสมาชิก

As a ผู้ใช้งาน
I want สมัครสมาชิกเพื่อสร้างบัญชี
So that สามารถเข้าใช้งานระบบและจัดเก็บข้อมูลส่วนตัวได้

**Acceptance Criteria**

- [ ] AC1: ผู้ใช้สามารถกรอกข้อมูลที่จำเป็น เช่น ชื่อผู้ใช้ อีเมล และรหัสผ่าน
- [ ] AC2: ระบบตรวจสอบข้อมูลก่อนสร้างบัญชี
- [ ] AC3: ระบบไม่อนุญาตให้ใช้อีเมลหรือชื่อผู้ใช้ที่มีอยู่แล้ว
- [ ] AC4: ระบบแจ้งผลการสมัครสมาชิกเมื่อดำเนินการเสร็จ

**Priority**: Must
**Estimate**: M

**Scenario:** Main Scenario — สมัครสมาชิกและเริ่มใช้งานระบบ

- [ ] AC2: ระบบตรวจสอบข้อมูลบัญชีก่อนเข้าสู่ระบบ

**Scenario:** Main Scenario — ดูภาพรวมข้อมูลชีวิตผ่าน Dashboard

### Story US-11: ดูรายชื่อผู้ใช้งาน

So that สามารถตรวจสอบและบริหารจัดการผู้ใช้งานได้

- [ ] AC1: ผู้ดูแลสามารถเปิดหน้ารายชื่อผู้ใช้งานได้
- [ ] AC2: ระบบแสดงรายชื่อผู้ใช้งานพร้อมข้อมูลพื้นฐาน
- [ ] AC3: ผู้ดูแลสามารถค้นหาผู้ใช้งานได้

**Priority**: Must
**Estimate**: M
