# Final Reflection
--- 

## 1. What did you build?
    DaybyDay เว็บแอปพลิเคชันสำหรับช่วยผู้ใช้งานจัดการข้อมูลชีวิตประจำวัน

## 2. What problem did you solve?
    แก้ปัญหาเรื่องข้อมูลชีวิตส่วนตัวที่กระจัดกระจาย การที่ต้องใช้หลายแอปจัดการทั้งการเงิน งาน และสุขภาพ ทำให้เสียเวลา มองไม่เห็นภาพรวม ส่งผลให้วางแผนการเงินลำบาก หลงลืมงาน และละเลยการดูแลสุขภาพ จึงเข้ามาช่วยรวมและเชื่อมโยงข้อมูลทั้งหมดไว้ในที่เดียวเพื่อความสะดวกในการจัดการ

## 3. What technical decision are you proudest of?
    Python และ Docker เพราะช่วยให้พัฒนาระบบและนำไปใช้งานได้ง่ายขึ้น รวมถึงทำให้ระบบทำงานได้อย่างสม่ำเสมอในแต่ละสภาพแวดล้อม

## 4. What failure taught you the most?
    การพบปัญหาจากการตั้งค่าระบบ ทำให้เรียนรู้ว่าควรทดสอบอย่างรอบคอบและตรวจสอบข้อผิดพลาดทีละขั้นตอน

## 5. What would you do differently?
    จะวางแผนโครงสร้างระบบให้ชัดเจนตั้งแต่ต้น ทดสอบแต่ละส่วนอย่างสม่ำเสมอ

## 6. How did you embody Tip 52 (Delight Users)?
    ออกแบบระบบให้ใช้งานง่าย เข้าใจได้สะดวก และช่วยให้ผู้ใช้ทำงานได้รวดเร็วขึ้น

## 7. How did you embody Tip 53 (Sign Your Work)?
    ใช้ Git และ GitHub ในการจัดการเวอร์ชันโค้ด ติดตามการเปลี่ยนแปลง และแสดงให้เห็นถึงผลงานที่ตนเองมีส่วนร่วม

## 8. What value did this experience add to your SE journey?
    ช่วยพัฒนาทักษะด้านเทคนิค การแก้ปัญหา การทำงานเป็นทีม และทำให้เข้าใจกระบวนการพัฒนาซอฟต์แวร์อย่างเป็นระบบมากขึ้น
