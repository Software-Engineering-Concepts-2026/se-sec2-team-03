# Project Proposal: LifeSync (Life Data Dashboard)

## Theme
Life Data Dashboard — เลือกธีมนี้เนื่องจากปัจจุบันข้อมูลพฤติกรรม สุขภาพ การเงิน และการทำงานของผู้ใช้กระจัดกระจายอยู่ตามแอปพลิเคชันต่างๆ (เช่น Apple Health, KBank, Notion, Google Calendar) การสร้างระบบศูนย์รวมข้อมูล (Unified Dashboard) ที่สรุปผลภาพรวมในหน้าเดียวจะช่วยลดเวลาการสลับหน้าจอ และช่วยให้ผู้ใช้งานนำตัวเลขเชิงสถิติไปตัดสินใจปรับปรุงชีวิตประจำวันได้อย่างมีประสิทธิภาพ

## Project Name
DayByDay

## Persona หลัก
กิตติศักดิ์ "กิต" ชัยวงศ์ (อายุ 32 ปี): ผู้จัดการโครงการ (Project Manager) บริษัทเทคโนโลยีขนาดกลางในกรุงเทพฯ มีพื้นฐานเป็นนักพัฒนาซอฟต์แวร์ ชอบวิเคราะห์ข้อมูลด้วยตัวเลขเพื่อตัดสินใจ กิตต้องรับผิดชอบงานที่มีความกดดันสูง พร้อมกับดูแลภรรยาและลูกสาวอายุ 3 ขวบ เขาต้องการบริหารเวลา ลดการทำ OT รักษาสุขภาพ (ลดน้ำหนัก 5 kg) และออมเงินกองทุนฉุกเฉิน แต่ประสบปัญหาเรื่องข้อมูลกระจัดกระจาย การคีย์ข้อมูลใช้เวลานาน และกังวลเรื่องความถูกต้องของสถิติรวมถึงความเป็นส่วนตัวของข้อมูล (Data Privacy)

## Value Proposition
* **ปัญหาที่แก้:** ข้อมูลการเงิน สุขภาพ และเป้าหมายกระจายอยู่หลายแอปฯ ทำให้เสียเวลาในการสลับหน้าจอและคีย์ข้อมูลทุกเช้า อีกทั้งขาดหน้าสรุปภาพรวมที่ผสานข้อมูลเข้าด้วยกัน
* **คุณค่าที่ได้รับ:** แดชบอร์ดศูนย์รวมข้อมูลที่แสดงภาพรวมสุขภาพ การเงิน และเป้าหมายรายวัน/สัปดาห์ในหน้าเดียว พร้อมระบบป้อนข้อมูลที่รวดเร็ว มี Validation ป้องกันสถิติบิดเบือน และรักษาสิทธิ์ความเป็นส่วนตัวของข้อมูลผู้ใช้

## MoSCoW Priorities
* **Must Have:**
  * หน้า Unified Overview Dashboard สรุปผลภาพรวมสุขภาพ (ก้าวเดิน/น้ำหนัก), การเงิน (รายจ่าย/กองทุนฉุกเฉิน) และเป้าหมายงาน
  * ระบบบันทึกข้อมูลประจำวันแบบรวดเร็ว (Quick Daily Logger) พร้อม Input Data Validation ป้องกันข้อมูลผิดพลาด
* **Should Have:**
  * ระบบติดตามเป้าหมายส่วนบุคคลพร้อม Progress Bar (ติดตามเป้าหมายลดน้ำหนัก 5 kg, ชั่วโมง OT และกองทุนฉุกเฉิน)
  * ระบบกรองข้อมูลและซ่อน/แสดงหมวดหมู่ข้อมูลตามความเป็นส่วนตัว (Category Filter & Privacy Toggle)
* **Could Have:**
  * ระบบส่งออกรายงานสรุปผลรายสัปดาห์/รายเดือน (Export Weekly Summary to CSV/PDF)
* **Won't Have (this term):**
  * การเชื่อมต่อ API อัตโนมัติโดยตรงกับแอปธนาคารหรืออุปกรณ์ Apple Watch แบบ Real-time Direct Sync (เน้นการ Manual Input & Import File ในเฟสนี้เนื่องจากข้อจำกัดด้านความปลอดภัย)

## Risks & Assumptions
* **Assumptions:**
  * ผู้ใช้ยินดีสละเวลา 3–5 นาทีต่อวันในการป้อนข้อมูลเข้าสู่ระบบ หากระบบมี UI ที่ใช้งานง่ายและมี Data Validation ที่แม่นยำ
  * ผู้ใช้ให้ความสำคัญกับความเป็นส่วนตัว (Data Privacy) และต้องการให้ข้อมูลจัดเก็บอย่างปลอดภัย
* **Risks:**
  * ผู้ใช้อาจรู้สึกว่าการคีย์ข้อมูลเองยังคงใช้เวลา หากแบบฟอร์มบันทึกข้อมูลไม่กระชับพอ
  * การคำนวณค่าเฉลี่ยสถิติอาจคลาดเคลื่อนหากผู้ใช้ลืมลงข้อมูลบางวัน (ต้องมีระบบจัดการ Missing Data/Default values)
